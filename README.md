# 퍼스트몰 API 기술지원 저장소

퍼스트몰(Firstmall) API 사용 및 연동 과정에서 발생하는 기술 문의를 접수하고 답변하는 공식 기술지원 저장소입니다.

## 📌 운영 안내

이 저장소는 [Discussions](../../discussions)를 중심으로 운영됩니다.

| 카테고리 | 용도 |
|---|---|
| 📢 공지사항 | API 운영 및 변경 사항 관련 공지 |
| 💬 기술 문의 | API 기술 문의 및 답변 |
| ❓ 자주 묻는 질문 | 자주 접수되는 문의 모음 |

## 💬 기술 문의 방법

1. 문의 전 **자주 묻는 질문**과 기존 **기술 문의** 게시글을 먼저 검색해 주세요.
2. 동일한 문의가 없다면 **기술 문의** 카테고리에 새 게시글을 등록해 주세요.
3. 게시글 작성 시 문의하려는 **API 종류를 레이블로 지정**해 주세요. (예: `상품`, `주문/배송`, `회원`, `인증`)

### 문의 시 포함해 주세요

- 호출한 API 엔드포인트 및 HTTP 메서드
- 요청 파라미터 예시 (민감정보 제외)
- 응답 결과 또는 오류 메시지
- 발생 일시

## ⚠️ 보안 주의사항

아래 정보는 **공개 게시판에 절대 게시하지 마세요.** 게시 확인 시 별도 통보 없이 삭제되며, 노출된 인증 정보는 무효화 처리될 수 있습니다.

- API Key, Secret, 인증 토큰
- 고객 개인정보 (이름, 연락처, 주소, 이메일 등)
- 실제 주문 정보, 회원 정보
- 서버 접속 정보, DB 접속 정보
- 쇼핑몰 관리자 계정 정보

요청/응답 예시를 첨부할 때는 반드시 민감한 값을 `***` 등으로 마스킹해 주세요.
